# 🌸 Iris Flower Classification

This project is part of a **Data Science Internship Task**.  
The goal is to classify iris flowers into one of three species — **Setosa, Versicolor, Virginica** — based on their measurements.

---

## 📂 Dataset
The dataset is publicly available on [Kaggle](https://www.kaggle.com/) and also comes with the **Scikit-learn library**.  
It contains **150 rows** with the following features:

- **Sepal Length** (cm)  
- **Sepal Width** (cm)  
- **Petal Length** (cm)  
- **Petal Width** (cm)  
- **Species** (target variable: Setosa / Versicolor / Virginica)  

---

## 🚀 Project Workflow
1. Import the dataset  
2. Perform **data preprocessing & visualization**  
3. Train models using **Machine Learning algorithms** (e.g., Logistic Regression, Decision Tree, Random Forest, SVM, KNN)  
4. Evaluate model performance with accuracy and confusion matrix  
5. Choose the best performing model  

---

## 🛠️ Technologies Used
- Python 🐍  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  

---

## 📊 Results
- Model trained to classify iris flowers with high accuracy (>95% using most ML algorithms).  
- Visualization of flower features shows clear separation between species.
